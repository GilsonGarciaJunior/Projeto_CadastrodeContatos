# 📱 Cadastro de Contatos

Projeto desenvolvido para criar uma aplicação simples de **cadastro e listagem de contatos**, permitindo inserir nome e telefone e visualizar os contatos cadastrados em uma tabela.

O projeto foi desenvolvido utilizando **HTML5, CSS3 e JavaScript**, com foco na prática de manipulação do DOM, eventos, validação de dados e criação de interfaces com formulários e tabelas.

## 🚀 Funcionalidades

* Cadastro de nome e telefone.
* Exibição dos contatos cadastrados em uma tabela.
* Validação dos campos obrigatórios.
* Verificação para impedir o cadastro de números de telefone duplicados.
* Limpeza automática dos campos após o cadastro.
* Interface simples e organizada.

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura da aplicação.
* **CSS3** — estilização e layout.
* **JavaScript** — lógica da aplicação e manipulação do DOM.
* **Google Fonts** — utilização da fonte Roboto.

## 💡 Como funciona

O usuário informa o **nome** e o **telefone** no formulário e clica em **Cadastrar**. O JavaScript captura os dados, verifica se o telefone já foi cadastrado e, caso seja um novo número, adiciona as informações à tabela de contatos.
Caso o número já exista, uma mensagem de alerta é exibida informando que o telefone já foi inserido.
